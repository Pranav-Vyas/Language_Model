# Phase 3 — attention re-analysis, pretrained vs finetuned (T3.10)

Generated by `scripts/build_attention_report.py` from `report/phase3/<tree>/attention_compare.json`. The Phase-2 toolkit (`<tree>/eval/attention_analysis.py`) is imported unchanged, so these numbers and the Phase-2 ones come from the same code. Finetuned values are the mean of 3 finetuning seeds.

Two probe sets are reported side by side. `corpus` is held-out natural text built with the exact Phase-2 call, so it asks whether finetuning *damaged* the language model. `reasoning` is held-out reasoning prompts, so it asks what finetuning *built*. A change on both is global; a change only on `reasoning` is task-specific.

> The reasoning probes are all one pattern at one exact token length. Padding a batch to a common length is not an option here: these models have learned absolute positional embeddings and `forward()` takes no attention mask, so a pad token is attended to like any other and would silently corrupt every statistic — the same root cause as the right-padding bug fixed in `reasoning_metrics.py`.

## 1. Layer-mean statistics

| probe set | metric | Model H (Hindi) pre → ft (Δ) | Model L (Nepali) pre → ft (Δ) |
|---|---|---|---|
| corpus | normalised entropy | 0.7400 → 0.7076 (-0.0324) | 0.7743 → 0.7691 (-0.0052) |
| corpus | mean attention distance (tokens) | 14.52 → 13.83 (-0.69) | 13.01 → 12.63 (-0.37) |
| corpus | content dependence | 0.02733 → 0.02894 (+0.00161) | 0.02677 → 0.02781 (+0.00105) |
| reasoning | normalised entropy | 0.6816 → 0.5831 (-0.0984) | 0.7114 → 0.6418 (-0.0696) |
| reasoning | mean attention distance (tokens) | 4.96 → 4.57 (-0.38) | 4.83 → 4.57 (-0.26) |
| reasoning | content dependence | 0.06990 → 0.08148 (+0.01158) | 0.06854 → 0.08782 (+0.01928) |

- **Model H (Hindi)**: entropy falls 0.0984 on the reasoning probes vs 0.0324 on natural text (3.0×).
- **Model L (Nepali)**: entropy falls 0.0696 on the reasoning probes vs 0.0052 on natural text (13.5×).

Both models sharpen more on reasoning prompts than on natural text, but the magnitudes are not comparable: Model H's reasoning-probe entropy drop is 1.4× Model L's (0.0984 vs 0.0696). The answer-position measurement separates them further. Model H ends 0.106 above the uniform baseline with its best head at 0.918 in layer 9; Model L ends 0.100 above baseline with its best head at 0.878 in layer 9.

Both models build a late-layer answer-retrieval circuit: Model H's best head reaches 0.918 (±0.012 across seeds) against the 0.250 baseline, with the layer mean 0.106 above baseline; Model L's best head reaches 0.878 (±0.020 across seeds) against the 0.250 baseline, with the layer mean 0.100 above baseline. Notably the strongest head is the same index in both independently trained models (L9H4 and L9H4) — convergence on a solution, not a shared initialisation, since the two models share no weights, no tokenizer and no data.

Measured at the position whose logits actually emit the entity — the final token of `prompt + " उत्तर: "`, not the last token of the prompt, which emits the answer-marker word two steps earlier. ## 3. Verification: the corpus probes reproduce Phase 2 exactly

The `corpus` probe set is built with the exact Phase-2 call on the exact Phase-2 checkpoint, so the *pretrained* half of this comparison must equal the committed `report/phase2/<tree>/attention.json` head for head. Largest absolute disagreement across all heads:

| tree | heads compared | normalised entropy | mean attention distance (tokens) | content dependence |
|---|---:|---:|---:|---:|
| Model H (Hindi) | 60 | 3.0e-07 | 1.1e-05 | 1.6e-08 |
| Model L (Nepali) | 60 | 1.8e-07 | 5.7e-06 | 3.7e-09 |

These are float32 rounding differences, so the pretrained baseline here is the Phase-2 model itself and every delta below is attributable to the finetune.
